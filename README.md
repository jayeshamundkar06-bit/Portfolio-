# ⛏️ Jayesh Amundkar — Minecraft-Themed Cinematic Developer Portfolio

A production-quality personal developer portfolio website inspired by a continuous cinematic Minecraft world. Visitors explore Jayesh's developer journey by scrolling through the world from the Overworld Plains to the Nether Portal.

---

## 🌟 Key Highlights & Chapters

- **Hero: Welcome to My World** — Overworld sunrise landscape with live character animation and quick status HUD.
- **Chapter I: The Enchanted Library** — Interactive 3-page glowing book with bio, academic foundation, and education scrolls (SSC 85%, HSC 60%, B.Sc.IT 8.36 CGPA at RJ College).
- **Chapter II: The Armory & Stable** — Minecraft inventory slots with custom rarity tiers, enchantments, and lore for Programming Languages, Web Technologies, Databases, Tools, and Concepts.
- **Chapter III: Player Attributes** — Minecraft HUD status screen showing developer strengths as active buffs.
- **Chapter IV: Quest Completed** — Verified Java Web Developer Intern bounty board at Code Alpha.
- **Chapter V: My Builds & Village** — Interactive architectural sanctums for **Wellify**, **Neuro Sketch**, **Vigor AI**, and **Build My PC** with feature deep-dives.
- **Chapter VI: Advancements Made!** — Achievement cards with XP for certifications (Java Web Developer, TATA Cybersecurity Analyst, Generative AI 2026, AWS to Azure Migration 2026).
- **Chapter VII: The Dungeon** — Deepslate mob-slaying room for Problem Solving, Data Structures, Algorithms, and LeetCode link.
- **Chapter VIII: The Nether Portal** — Swirling obsidian portal, quick email copy button, social links (GitHub, LinkedIn), and simulated server chat broadcast.
- **Audio Engine & Easter Eggs** — Procedural Web Audio 8-bit sound effects, secret loot chest with diamond confetti, and `/` Command Block console (`/help`, `/tp <section>`, `/give diamond`, etc.).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router) + React 18
- **Styling**: Tailwind CSS + Custom Minecraft Pixel UI
- **Icons**: Lucide Icons
- **Animation**: Canvas 2D/3D Procedural Voxel Engine & Shaders + Canvas Confetti
- **Audio**: Web Audio API Procedural Synthesizer (No external copyrighted files required)
- **Language**: TypeScript

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## ⚙️ Customization & Updating Content

All data is decoupled into clean TypeScript configuration files in `src/data/`:
- `src/data/profile.ts` — Bio, contact info, education, strengths, social URLs.
- `src/data/projects.ts` — Project descriptions, tech stacks, and feature lists.
- `src/data/skills.ts` — Skill categories, item names, enchantments, and rarity tiers.
- `src/data/experience.ts` — Internship responsibilities and achievements.
- `src/data/certifications.ts` — Certifications, issuers, and XP values.
- `src/data/dsa.ts` — DSA topics and LeetCode profile URL.
- `src/data/easterEggs.ts` — Minecraft console commands and responses.

### 🎬 Replacing Cinematic Videos
If you render custom Minecraft WebM or MP4 videos, you can place them into `/public/assets/cinematics/`:
- `hero.webm`
- `about.webm`
- `skills.webm`
- `projects.webm`
- `contact.webm`
